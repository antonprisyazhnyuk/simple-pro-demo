# ⚠ ЧЕСТНО ПРО ГРАНИЦЫ ЭТОГО ФАЙЛА, чтобы на него не полагались вслепую:
# robots.txt читается роботом ТОЛЬКО из корня домена. Если сборка ляжет в подкаталог
# проекта (https://<user>.github.io/<repo>/), краулер спросит
# https://<user>.github.io/robots.txt — то есть ЭТОТ файл он не увидит вообще, и запрет
# не сработает. Он работает только когда сайт стоит в корне домена (репозиторий
# <user>.github.io либо свой домен).
# Поэтому НЕСУЩАЯ мера — <meta name="robots" content="noindex, nofollow"> на КАЖДОЙ
# странице: она действует независимо от того, куда легла сборка. Этот файл — второй
# контур, а не первый.
# Заголовок X-Robots-Tag был бы третьим, но GitHub Pages не даёт задавать заголовки.

User-agent: *
Disallow: /
