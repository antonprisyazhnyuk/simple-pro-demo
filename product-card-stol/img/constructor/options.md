# Опции конструктора — Стол островной (Simple PRO)

Источник: https://simple-pro.com/catalog/stoly_laboratornye/stol_ostrovnoy/

Снимок отражает опции для выбранного на странице варианта ширины **900 мм** (значение по умолчанию при загрузке страницы). Панель опций подгружается динамически при смене ширины/материала на живом сайте; при статичном скачивании HTML доступен только вариант, который был активен в момент снятия слепка. Опции для 1200/1500/1800 мм на этой странице НЕ зафиксированы (см. `report.md`).

Всего опций на снимке: **59** (48 тумб/ящиков + 11 аксессуаров).
