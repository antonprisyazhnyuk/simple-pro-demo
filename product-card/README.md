# Карточка товара Simple PRO

Вёрстка карточки товара (шкаф вытяжной химический) на живых данных каталога
simple-pro.com. Десктоп 1920 + мобильный слой (брейкпоинт 720 / проверка 360).

## Как запустить

Статические файлы, без сборки и зависимостей. Откройте `index.html` в браузере
или поднимите любой статический сервер из корня папки:

    python3 -m http.server 8000

Затем откройте http://localhost:8000/

## Структура

    index.html                     разметка страницы
    css/
      tokens.css                   токены ДС (цвет, типографика, отступы) в CSS-переменных,
                                   @font-face, базовые стили
      components.css               общие компоненты (кнопки и их семьи)
      block-01-first-screen.css    первый экран: шапка, галерея, панель товара, табы
      blocks.css                   остальные блоки страницы
    js/app.js                      интерактив без зависимостей
    assets/                        изображения, иконки, шрифты

Интерактив (`js/app.js`, без библиотек): трансформация первого экрана по скроллу,
галерея с миниатюрами, 3D-просмотр модели (вращение по движению курсора), табы,
онлайн-конструктор с расчётом стоимости, сравнительная таблица, мега-меню каталога,
выбор региона, копирование контактов.

## Технические заметки

- Размеры — rem/em/%, без px. Цвета и типографика — только через переменные токенов
  (`tokens.css`); переносятся в CSS-переменные шаблонов Bitrix напрямую.
- Шрифты — оба самохостинг, без внешних сетей: заголовки — Simplepro Display (`assets/`);
  текст — Geologica woff2 в `assets/fonts/` (веса 300/400/600, сабсеты cyrillic/latin ±ext;
  @font-face в `tokens.css`, браузер тянет только нужный сабсет по unicode-range).
- Состояния интерактивных элементов включают клавиатурный фокус (`:focus-visible`).

## Мобильная версия

Мобильный слой собран в `css/mobile.css` (медиазапрос `max-width: 720px`, проверка на 360):

- **Готово:** первый экран (компактная шапка, галерея с главным кадром и рейкой миниатюр,
  панель товара с табами в вертикальном потоке, CTA-мессенджеры) и блоки 3–14 (линейка
  моделей, преимущества, видео, надёжность, конструктор, таблица, тендер, футер) —
  адаптированы под узкий экран без горизонтальной прокрутки.
- **Придёт апдейтом:** мобильное бургер-меню каталога и нижняя навигационная панель
  (разметка/обработчики заложены), свайп-карусель главного кадра с точками-индикаторами.
- **Правило заголовка hero:** заголовок всегда занимает две строки (кегль не меняется):
  длинный переносится естественно (`text-wrap: balance`), короткий делится пополам по
  словам JS-хелпером. Сохраните это правило при переносе в Bitrix.

## Известные ограничения

- Отправка форм и действия «В корзину» / «Отправить» — заглушки: серверной части нет.
- Видеообзор — временный общий ролик бренда; заменить на модельный по получении от клиента.
